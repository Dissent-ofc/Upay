# HOW TO GET MORE URLS YOURSELF:
#   1. Go to https://archive.org/details/ncert-<bookcode> (e.g. ncert-jesc1
#      for Class 10 Science, ncert-jemh1 for Class 10 Math).
#   2. Click through to the file listing (or go straight to
#      https://archive.org/download/ncert-<bookcode>).
#   3. Each chapter is <bookcode><NN>.pdf — copy its link.
#
# NCERT book codes follow a pattern: first letter = class (e/f/g/h/i/j/k/l
# roughly map to classes 6-12), rest identifies subject/book. Easiest way
# to find a code: search "archive.org ncert class <N> <subject>".
